wstunnel-android

wstunnel 的第三方 Android 客户端，提供两个 APK 形态：基于 sockstun 的全设备 VPN 版， 以及只暴露本地 SOCKS5 端口的轻量服务版。

非官方项目：本项目为 wstunnel 的第三方客户端，与 wstunnel 上游作者 （Erèbe - Romain Gerard）无隶属、授权或背书关系。“wstunnel” 名称仅用于说明所连接的协议与服务端。

产品形态

完整 VPN 版

wstunnel VPN

cn.bujian.wstunnel · v0.2.1-beta

  • 以 sockstun（hev-socks5-tunnel）为基底的全设备 VPN
  • 内嵌 wstunnel v9.7.4 客户端，支持最多 13 组 Profile
  • 按 App 分流、IPv4/IPv6、远程 DNS、UDP 经 TCP 中继
  • VPN 服务运行在独立的 :native 进程
已冻结

wstunnel Client

cn.bujian.wstunnel.client · v0.1.0-beta

  • 只运行 wstunnel 子进程，不做 VPN 接管
  • 对外暴露本地 SOCKS5 端口，供其他代理前端使用
  • 仓库保留已发布内容，作为独立项目不再参与构建发布

链路与工作原理

VpnService建立 tun 虚拟网卡
→
tun2sockshev-socks5-tunnel 转发流量
→
本地 SOCKS5127.0.0.1:<端口>
→
wstunnel子进程封装 WebSocket / HTTP2
→
wstunnel server远端服务端出口

上游只有 wstunnel 一个来源：tun2socks 的 SOCKS5 出口恒为 127.0.0.1:<当前 Profile 的本地端口>，不存在回落到外部 SOCKS5 的第二来源。 wstunnel 进程同一时刻仅有一个，参数变化时自动重启。

技术规格

语言 / 构建Kotlin、Java、C（NDK Build）
运行要求Android 7.0+（minSdk 24），targetSdk 34
ABIarm64-v8a
核心组件hev-socks5-tunnel、lwip、hev-task-system、libyaml、wstunnel v9.7.4
UI 依赖AndroidX AppCompat 1.7.0、Material Components 1.12.0
日志filesDir/wstunnel.log，主进程与 :native 进程共享

构建

# 完整 VPN 版
cd app
./gradlew assembleRelease

# 纯 SOCKS5 服务版（已冻结，仅供归档）
cd client
./gradlew assembleRelease

签名配置位于各模块的 store.properties / build.gradle.kts， 请使用自己的密钥，不要将密码写入仓库。
